# Yutani Foundation Demo Script

This script is designed for a 4 to 6 minute live demo.

## Before Starting

Make sure these are ready:

- Backend is running
- Frontend is running
- You are already on the sign-in page
- Internet is available if AI assistant is enabled

## Opening Line

"Today I am presenting Yutani Foundation, a full-stack project management system built to help teams manage workspaces, projects, tasks, collaboration, and analytics from a single platform."

## Part 1: Authentication

What to do:

- Open the sign-in page
- Sign in with your demo account

What to say:

"The application starts with user authentication. Users can sign up, sign in, reset passwords, and securely access their data using JWT-based authentication."

## Part 2: Dashboard

What to do:

- Show the dashboard screen
- Point to stats cards and charts

What to say:

"After login, the user reaches the dashboard. This page gives an overview of total projects, total tasks, tasks in progress, completed tasks, and other productivity insights. This helps users and managers quickly understand current progress."

## Part 3: Workspace Management

What to do:

- Open the workspaces page
- Open an existing workspace or create one

What to say:

"The system is organized around workspaces. Each workspace represents a team or department. Inside a workspace, users can collaborate, invite members, and organize multiple projects."

## Part 4: Invite Member

What to do:

- Open invite dialog
- Explain roles

What to say:

"Workspace members can be invited with roles. This makes collaboration controlled and structured, especially in team environments."

## Part 5: Project Creation

What to do:

- Open Create Project
- Fill title, description, dates, tags, and members
- Create the project

What to say:

"Inside each workspace, users can create projects. A project includes title, description, status, timeline, tags, and members. The creator is also included automatically to avoid access issues."

## Part 6: Project Details

What to do:

- Open the created project
- Show project status and progress

What to say:

"Each project has its own details page where progress can be monitored. Tasks are grouped by status to make tracking simple."

## Part 7: Task Management

What to do:

- Add a task
- Show priority, due date, assignees
- Mention subtasks/comments/activity

What to say:

"Tasks are the core work units of the system. A task can include priority, due date, assignees, subtasks, comments, and archive support. This allows detailed tracking of work progress."

## Part 8: Archived Tasks

What to do:

- Open archived page

What to say:

"Completed or inactive tasks can be archived. This keeps the main interface clean while still preserving task history."

## Part 9: Dark Mode

What to do:

- Click the dark mode toggle

What to say:

"For better usability, I added a dark mode toggle, which improves accessibility and user experience."

## Part 10: AI Assistant

What to do:

- Open the AI chatbox
- Ask a simple project-planning question

Suggested prompt:

- "Help me break a website redesign into tasks."

What to say:

"The application also includes an AI assistant. It helps users understand the current page, break down work, plan projects, and improve productivity."

## Closing Line

"In summary, Yutani Foundation is a modern project management platform combining authentication, collaboration, analytics, and AI guidance into one system."

## Shorter 2-Minute Version

If you are short on time, use this order:

1. Sign in
2. Show dashboard
3. Show workspace
4. Create project
5. Create task
6. Show AI assistant
7. Show dark mode

Short closing:

"This project demonstrates a complete full-stack workflow from authentication to analytics and AI support."
